# Der Aluhut

Partyspiel über Verschwörungstheorien für einen Abend im selben Raum. Jede Person präsentiert eine zugeloste Theorie mit drei Pflichtwörtern, das Publikum spielt am Handy Bingo, rät die Wörter und bewertet die Überzeugungskraft. Ein Admin steuert die Phasen.

## Starten

Voraussetzung: Node ≥ 22.13, pnpm.

```bash
pnpm install
pnpm dev
```

Die App läuft dann unter http://localhost:3000.

## Weitere Befehle

- `pnpm test`: Tests
- `pnpm typecheck`: Typprüfung
- `pnpm build`: Produktions-Build
